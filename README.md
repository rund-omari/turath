# بطاقة حصر عناصر التراث الثقافي غير المادي — تطبيق ويب

نسخة ويب عربية RTL مبنية على ملف Word الرسمي المرفوع لبطاقة الحصر في محافظة العاصمة عمّان.

## ما يفعله النظام
1. يعرض حقول البطاقة الرسمية كاستمارة ويب سهلة من الهاتف أو الكمبيوتر.
2. يدعم خيارات تصنيف العنصر وأهداف التنمية المستدامة، بيانات الممارسين، بيانات الراوي، والصور/الفيديو.
3. عند الإرسال يحفظ البيانات والمرفقات في مساحة التخزين الخاصة بالخادم.
4. يعبئ نسخة من قالب Word الرسمي نفسه ويحفظها لكل طلب.
5. يحول Word إلى PDF تلقائياً بواسطة LibreOffice.
6. يعطي كل طلب رقماً مرجعياً، ويوفر لوحة `/admin` لتنزيل Word وPDF.

## التشغيل المحلي
```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```
ثم افتح `http://localhost:8000`.

## النشر على Railway
المشروع يحتوي `Dockerfile` و`railway.toml`. اربط المشروع بـ Railway، وأضف متغيرات البيئة:
- `ADMIN_USER`
- `ADMIN_PASSWORD` (غيّرها إلى كلمة قوية)
- `DATA_DIR=/data` عند استخدام Volume دائم.

يجب إضافة Volume دائم لأن SQLite وملفات الطلبات يجب ألا تضيع عند إعادة النشر.

## ملاحظة
القالب الرسمي موجود في `app/templates_docs/official_template.docx`. تم الحفاظ على بنية الجدول الرسمية، وتعبئة الإجابات في خلاياها عند إنشاء نسخة الطلب.
